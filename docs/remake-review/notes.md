I plan to approach the new version slightly differently. By default the assumption will be that I continue with the same feature set, but I need some major changes. First of all, the     
  document editor will no longer be the primary feature. Everything will build around the canvas (I need a better name for that). The additional features will be present, but the priority   
  is clean user friendly navigation and usability in the canvas space. There will be additions of versatile widgets, sections can be added with notes, stats, etc. Primary sources for notes  
  will be syncing with Google docs and Obsidian. MCP will be set up with baseline tools but will not be so central to the concept. It will be just another tool albeit wide-spread and very   
  capable. It will also be able to be completely disabled. I need the architecture to support advanced features from the start. Namely, cloud sync and multi-user support need to be          
  considered intensely within the architecture. It is also much more critical that performance is managed. CI/CD was good but became overly complex. More care needs to be put into the new   
  version to ensure it actually meets needs, is effective, and is sustainable with valuable, responsive feedback. The graph engine is still important in order to be able to effectively      
  navigate obsidian vaults as well as vaults still created using this tool. The tool needs to have a better persistent config and vault switching/inclusion system. The command centre will   
  be much more pivotal in the redesign along with the associated player views. The DM needs to have an immense capability of tools at their disposal and a huge degree of flexibility in      
  terms of what is shown/provided to players. Thought will need to go into how this is to be architected and uses canvases. It is likely that the command center will be the application      
  home. AI Creative partnership pieces will be simplified but remain extensible. I need the ability to easily tack on new web/local agents. It is important that algorithmic elements are     
  highlighted much more and emphasised in the development. AI should be providing only it's particular brand of input with the formatting streamlining that. Multi-platform usability is      
  incredibly important. As much as possible, processing and display (frontend, backend) need to be decoupled so the processing can be identical on any device (simplified for slimmer         
  devices perhaps) but have completely unique GUI experiences bases on ratio, input type, etc. Storage in cloud is going to be a key feature but should still assume local storage by         
  default. The various collabhoration features will now be key inclusions in the new application and stand as prime features. This will require additional thought on tooling, access, etc.   
  Extensibility and ecosystem will be removed entirely from scope. Maps are another primary feature in the new version. These will of course be embeddable into the command center canvas.    
  The maps will need to become an advanced custom map creation tool with generation systems, intuitive imports, basic map building/drawing. Beyond creation though, it is imperative that     
  the layering and tagging system be highly effective. Layering could mean like heightmap, style filters, watersheds, waterways, roads, transport systems, POIs, etc. It needs to be very     
  capable. It also needs to be very easy to nest maps inside one another with smooth scroll zooming in and out. The PC management suite will be adapted to be a versatile tool for character  
  creation and management. Simplified creation will be available for DMs, structured creation for players with their characters, level-up guides, etc. This will also be available to the     
  DM who may help players with this collaboratively. DM can make overrides to certain things that need to be clear. All characters need to have a clear way to expose data such that widgets  
  can easily access and manage things and it can be embedded effectively. The audio and atmosphere stuff will be important in the new version but need to have additional thought put into    
  the design. Leave out community content stuff
