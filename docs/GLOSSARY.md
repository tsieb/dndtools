# Glossary

Domain and architecture terminology used across DND Tools documentation and code. The
current runtime is the React app (`apps/gm-react`) on the framework-free core
(`packages/core`); terms describing the retired SvelteKit/v1 runtimes are marked
_historical_.

---

| Term                     | Definition                                                                                                                                                                                | Canonical source                                             |
| ------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------ |
| **Vault**                | A user's campaign dataset managed by DND Tools. Persisted client-side via Dexie/IndexedDB (no longer a directory of markdown files). Fully user-owned.                                     | `apps/gm-react/src/platform/storage/coreStore.ts`            |
| **Processing Core**      | The framework-independent package that owns all durable mutations, reducers, permissions, queries, schemas, and registries. Imports no React/DOM/Node/cloud (boundary lint-enforced).     | `packages/core`, `packages/core/scripts/boundary-lint.ts`    |
| **Command**              | The unit of durable mutation. Every state change enters the Processing Core as a command and is validated, permission-checked, and reduced. Dispatched via `dispatchCommand`.              | `packages/core/src/commands/dispatch.ts`                     |
| **ContentItem**          | The base content record. A note is a `kind: 'text'` item; a Vault Object is a `kind: 'object'` item with a typed subtype.                                                                  | `packages/core/src/commands/types.ts`                        |
| **Vault Object**         | A structured, embeddable entity (stat block, encounter, `dice-table`, image, etc.) stored as a `ContentItem` (`kind: 'object'`) with typed frontmatter. Distinct from plain text notes.   | `packages/core/src/commands/vault-object.ts`                 |
| **Actor-scoped query**   | A read surface resolved against the requesting actor's identity and permissions, so DM-private content is never returned to a player. Reads never mutate.                                  | `packages/core/src/queries/`                                 |
| **View-model**           | A player-safe projection of session state replicated to remote players. Players never receive raw DM state — only the derived view-model.                                                 | `apps/gm-react/src/net/viewModels.ts`                        |
| **P2P remote play**      | LAN/serverless WebRTC transport for local remote players — DM host replicates player-safe view-models; player→DM messages are stamped command requests. No backend required.              | `apps/gm-react/src/net/`                                     |
| **E2EE cloud sync**      | End-to-end-encrypted campaign sync over the AWS backend for remote groups. The server stores only ciphertext; the vault key never leaves the client.                                      | `apps/gm-react/src/cloud/`, `packages/cloud-fns`             |
| **Cognito**              | AWS Cognito — the identity provider backing cloud authentication (sign-in, tokens). Cloud is optional; local-first works with no account.                                                  | `apps/gm-react/src/cloud/auth.ts`                            |
| **Dexie / IndexedDB**    | Dexie is the wrapper over the browser-native IndexedDB store used as the client persistence backend for the vault.                                                                         | `apps/gm-react/src/platform/storage/coreStore.ts`            |
| **MCP**                  | Model Context Protocol tool surface exposed to AI agents. Tools route through the Processing Core (no direct data access); the registry is a declared, fail-closed allowlist.              | `packages/core/src/mcp/tool-registry.ts`                     |
| **Staged Write**         | An MCP write held as a pending proposal requiring human approval rather than committing immediately — the default AI write mode.                                                           | `packages/core/src/commands/mcp-policy.ts`                   |
| **Quality-gate registry**| The declared gates the app is verified against: perf budgets, platform quality gates, security regression gates, and the cloud-sync gate. Consumed by `pnpm validate`/`pnpm gates`.        | `packages/core/src/platform/quality-gates.ts`                |
| **Wikilink**             | An `[[Note Title]]` cross-reference resolved to a Vault Object / ContentItem id. The primary linking mechanism.                                                                            | `packages/core/src/commands/vault-object.ts`                 |
| **Frontmatter**          | Structured metadata (title, tags, links, object type) attached to a ContentItem, kept in deterministic sync with body content.                                                            | `packages/core/src/commands/types.ts`                        |
| **Command board**        | A spatial board of widget tiles (trackers, dice, timers) used during live play. Rendered on a canvas.                                                                                      | `apps/gm-react/src/app/SceneBoardCanvas.tsx`                 |
| **POI**                  | Point of Interest. A spatial annotation on a map that links to a Vault Object.                                                                                                             | `packages/core/src/commands/map-annotations.ts`              |
| **Desktop shell**        | The Electron packaging of the React app (main + preload). The web app is primary; the shell adds desktop distribution and LAN discovery.                                                   | `apps/gm-react/electron/`                                    |
| **ADR**                  | Architecture Decision Record. A short document recording a significant technical decision. All ADRs live in `docs/adr/`.                                                                   | `docs/adr/README.md`                                         |
| **Initiative / Epic / Story** | Planning tiers: an Initiative is a major product dimension, an Epic a coherent capability, a Story a single reviewable PR-sized unit.                                                  | `docs/planning/PLANNING_TIERS.md`                            |
| **StorageAdapter** _(historical)_ | The v1 abstraction with FileSystem/Capacitor/IndexedDB implementations. Retired: the React app persists directly via the Dexie-backed `coreStore`.                             | —                                                            |
| **MCP Sidecar** _(historical)_    | The v1 stdio MCP server launched by Electron. Retired: MCP tools now live in `packages/core/src/mcp/` and route through the Processing Core.                                   | —                                                            |
| **Capacitor / Android** _(historical)_ | The v1 hybrid Android target. Retired; not a current shipped platform.                                                                                                    | —                                                            |
| **Runes Class** _(historical)_    | A Svelte 5 `$state`/`$derived` reactive class from the retired SvelteKit app (`archive/gm-svelte`).                                                                            | —                                                            |
