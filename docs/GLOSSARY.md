# Glossary

| Term                                       | Definition                                                                                                                                                                   | Canonical source                                                                |
| ------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| **Vault**                                  | A user's campaign dataset, persisted client-side in Dexie/IndexedDB (`dndtools-v2`) and fully user-owned.                                                                    | `apps/gm-react/src/platform/storage/coreStore.ts`                               |
| **Processing Core**                        | The framework-free package owning every durable mutation, reducer, permission, query, schema, and registry. Boundary lint-enforced.                                          | `packages/core`, `scripts/boundary-lint.ts`                                     |
| **Command**                                | The unit of durable mutation: validated, permission-checked, reduced by `dispatchCommand`, and appended to the operation log.                                                | `packages/core/src/commands/dispatch.ts`                                        |
| **SceneRuntime**                           | The app's single durable write choke point: runs the reducer, persists, notifies listeners; serializes dispatches with agent writes and storage maintenance.                 | `apps/gm-react/src/runtime/SceneRuntime.ts`                                     |
| **Actor-scoped query**                     | A read resolved against the requesting actor's identity and permissions (`*ForActor`), so DM-private content never reaches a player.                                         | `packages/core/src/queries/`                                                    |
| **View-model**                             | The player-safe projection of session state replicated to remote players; players never receive raw DM state.                                                                | `apps/gm-react/src/net/viewModels.ts`                                           |
| **ContentItem / Vault Object**             | The content record. A `note` is prose; an `object` carries a typed subtype (`character`, `quest`, `dice-table`, `faction`, …) validated by the vault-object schema registry. | `packages/core/src/state/content.ts`, `vault-object-schema.ts`                  |
| **Custom object type**                     | A DM-authored subtype in the reserved `custom:` namespace, projected through the same schema path as built-ins.                                                              | `packages/core/src/state/custom-object-type.ts`                                 |
| **Wikilink / Frontmatter**                 | `[[Title]]` cross-references resolved to content ids; structured metadata kept in sync with the body.                                                                        | `packages/core/src/state/markdown.ts`                                           |
| **Scene**                                  | An authored canvas of widget instances, regions, and player-view assignments, edited at `/scene/:id`.                                                                        | `packages/core/src/state/scene-state.ts`                                        |
| **Board / GM Screen**                      | The always-on live-play canvas at `/board`; the home scene rendered under a bounded policy.                                                                                  | `apps/gm-react/src/screens/Board.tsx`                                           |
| **Widget Definition / Package / Instance** | A widget type's declared shape; a distributable bundle of definitions with a trust review; one placed widget with layout, config, and binding.                               | `packages/core/src/state/widget-package-state.ts`                               |
| **System Package**                         | The rules vocabulary a table plays by (attributes, resources, conditions, dice, turn model, advancement), stored in the `systems` slice. D&D 5e and Generic ship built in.   | `packages/core/src/state/system-package.ts`                                     |
| **Combatant / Combat token**               | A participant in `session.combat` and its durable map placement keyed by `combatantId`, not by map.                                                                          | `packages/core/src/state/combat-tracker.ts`                                     |
| **POI**                                    | A point of interest: a map annotation that can link to a Vault Object or drill into a child map.                                                                             | `packages/core/src/state/map-annotations.ts`                                    |
| **Projection**                             | (a) A map's coordinate mapping (flat, equirectangular, web-mercator); (b) "project to players" pushes a map or scene to the player view.                                     | `packages/core/src/state/map-state.ts`                                          |
| **MCP / Staged write**                     | The tool surface exposed to AI agents; every write becomes a pending proposal a DM approves. AI proposes, never disposes.                                                    | `packages/core/src/mcp/tool-registry.ts`, `mcp/ai-boundary.ts`                  |
| **Co-DM**                                  | A base role with DM authority (read and author) but not campaign ownership (roles, grants, invites, vault settings).                                                         | `packages/core/src/state/permission-state.ts`                                   |
| **Privacy mode**                           | A per-vault choice: Private (E2EE, client-held keys) or Cloud-Enhanced (server-readable, gated `approved: false` until the phase-2 review).                                  | `packages/core/src/security/cloud-security-decision.ts`                         |
| **SYNC-017 / SEC-009**                     | The fail-closed gates that must be satisfied before cloud sync or a cloud release is allowed.                                                                                | `packages/core/src/sync/cloud-sync-gate.ts`, `security/cloud-security-model.ts` |
| **Quick Map**                              | The touch-safe map workspace Android always uses: full geometry preserved, precision authoring hidden, navigation the default.                                               | `apps/gm-react/src/platform/capabilities.ts`                                    |
| **Feature tier**                           | The progressive-disclosure level of a vault (`core`, `intermediate`, `advanced`) that gates which surfaces are shown.                                                        | `packages/core/src/state/onboarding.ts`                                         |
| **ADR**                                    | Architecture Decision Record, in `docs/adr/`.                                                                                                                                | `docs/adr/README.md`                                                            |
| **Story (`RC-LANE-n.m`)**                  | The unit of roadmap work: sized, phased, with declared dependencies and owned files.                                                                                         | `docs/planning/RC_ROADMAP.md`                                                   |
