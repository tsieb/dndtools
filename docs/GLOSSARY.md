# Glossary

Domain terminology used across DND Tools documentation and code.

---

| Term                 | Definition                                                                                                                                                                                     | Canonical source                                            |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------- |
| **Vault**            | A directory of markdown files managed by DND Tools. The root of a user's campaign notes. All data is stored here.                                                                              | `mcp/storage.ts`, `src/lib/types/storage.ts`                |
| **Vault Object**     | A structured, embeddable entity (stat block, character, image, etc.) stored as a special note type with typed frontmatter. Distinct from plain notes.                                          | `src/lib/types/object.ts`                                   |
| **StorageAdapter**   | The interface that abstracts all persistence operations. Three implementations exist: `FileSystemAdapter` (desktop), `CapacitorStorageAdapter` (Android), `IndexedDbStorageAdapter` (browser). | `src/lib/types/storage.ts`                                  |
| **MCP Sidecar**      | The Model Context Protocol server (`mcp/`) that exposes vault read/write tools to AI agents. Runs as a stdio process launched by Electron.                                                     | `mcp/index.ts`                                              |
| **Staged Write**     | An MCP write that creates a pending change record rather than committing immediately. Requires human approval in Settings → MCP tab. The default mode.                                         | `mcp/staged-storage.ts`                                     |
| **Direct Mode**      | MCP write mode where mutations commit immediately without staging. Enabled with `--direct` flag or `DNDTOOLS_MCP_STAGED=0`. Use only in controlled/test contexts.                              | `mcp/index.ts`                                              |
| **Wikilink**         | An `[[Note Title]]` cross-reference in markdown. Resolved to vault note IDs at parse time. The primary linking mechanism.                                                                      | `src/lib/markdown/`                                         |
| **Session Board**    | A dashboard of note tiles used during a live game session. Supports timers, dice, combat trackers, and note pinning.                                                                           | `src/lib/types/session-board.ts`                            |
| **Runes Class**      | A Svelte 5 class using `$state`/`$derived`/`$effect` runes for reactive state management. All state singletons in `src/lib/state/` follow this pattern.                                        | `src/lib/state/*.svelte.ts`                                 |
| **POI**              | Point of Interest. A spatial annotation on a map image that links to a vault note. Introduced in Epic 9.2.                                                                                     | `docs/planning/initiatives/I9-maps-spatial-intelligence.md` |
| **IPC**              | Inter-Process Communication. The Electron channel between the renderer (sandboxed) and the main process (trusted). All channels are named, typed, and schema-validated.                        | `electron/ipc-schemas.ts`                                   |
| **Schema Migration** | A versioned upgrade step that transforms vault data to a newer schema. Runs at startup with dry-run preview, checkpoint backup, and rollback support.                                          | `mcp/migrations.ts`, `docs/operations/SCHEMA_MIGRATIONS.md` |
| **Safety Snapshot**  | A full vault backup taken before high-risk operations (bulk import, migration, mass delete). Listed in Settings → System Health.                                                               | `src/lib/types/storage.ts`                                  |
| **ADR**              | Architecture Decision Record. A short document recording a significant technical decision, its context, and its consequences. All ADRs live in `docs/adr/`.                                    | `docs/adr/README.md`                                        |
| **Story**            | The atomic unit of planned work. One PR, one demonstrable outcome. Identified as `S<epic>.<n>` (e.g., `S1.2.3`).                                                                               | `docs/planning/PLANNING_TIERS.md`                           |
| **Epic**             | A group of 3–7 related Stories delivering a single coherent capability. Identified as `<I>.<n>` (e.g., Epic 1.4).                                                                              | `docs/planning/PLANNING_TIERS.md`                           |
| **Initiative**       | A group of 3–7 Epics delivering a major product dimension. 12 initiatives are defined.                                                                                                         | `docs/planning/initiatives/README.md`                       |
| **TODO(APP)**        | A documentation marker for planned-but-not-yet-implemented features. Must include: what's missing, why it matters, target milestone, risk.                                                     | `docs/README.md`                                            |
| **Frontmatter**      | YAML metadata block at the top of a markdown note, delimited by `---`. Stores title, tags, links, schema version, and object type.                                                             | `src/lib/markdown/frontmatter.test.ts`                      |
| **IndexedDB**        | Browser-native key-value store. Used by `IndexedDbStorageAdapter` (via Dexie.js) as the persistence backend for browser/PWA mode.                                                              | `src/lib/platform/storage/indexeddb-adapter.ts`             |
| **Capacitor**        | Hybrid app framework (formerly Ionic Capacitor). Wraps the SvelteKit renderer in a native Android shell. Used for the Android platform target.                                                 | `android/`, `docs/operations/MOBILE.md`                     |
