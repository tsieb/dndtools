## Summary

Brought the structured-object, wikilink-lifecycle, and calendar-field surfaces onto the design
tokens, preserving every functional testid.

- **`VaultObjects`** (UX-CONTENT-006/008/009): the schema-validated object create form, the
  wikilink **rename-and-propagate** form, and the broken-link **repair** form are now token-styled
  cards (44px controls, monospaced frontmatter editor, error tones, raised list rows). The schema
  registry, the live validation preview, and the actor-filtered broken-link list are unchanged.
- **`CalendarContent`** (UX-CONTENT-019): the date field is now **calendar-aware** — the month number
  reflects the active campaign calendar's month name ("Hammer"), and the timeline / item lists are
  token-styled cards with the chronological date rendered in the accent colour.
- **Backlinks panel (UX-CONTENT-010)**: retained in `NotesWorkbench` (backlinks + related-note jumps,
  cross-section labels, actor-filtered), already on the editor card from the editor-shell epic.

## Actor-safety / no-leak evidence

- Every surface reads/writes only through the actor-filtered content queries + durable commands:
  rename/repair targets come from the actor-visible note list, broken-link detection is
