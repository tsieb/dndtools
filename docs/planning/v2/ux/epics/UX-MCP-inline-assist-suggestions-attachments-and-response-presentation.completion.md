## Summary

Delivered **UX-MCP-008 (response presentation)** concretely and documented the live inline-assist
surfaces against the same contract. Agent responses arrive as the core's stable `McpResponseEnvelope`
(one shape for every tool/status), so the AI/MCP settings panel now includes a **"How agent responses
are presented" reference** (visible when AI is enabled) that renders each response status using the
real contract fields:

- **status badge** (ok / staged / denied / error) with tone,
- a generic, non-leaking **summary**,
- **warnings** rendered SEPARATELY from data,
- **citations** as id/kind-only chips (never cited content — no leak side-channel),
- **remediation actions**, and
- a structured, non-leaking **error** (code + message + field issues).

A note records that inline assist, suggestion chips, and attachment (semantic-bundle) surfaces activate
with the deferred AI transport but already follow this envelope contract for their result presentation.
