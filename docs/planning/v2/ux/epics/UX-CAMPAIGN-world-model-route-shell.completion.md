## Summary

Replaced the Campaign route's honest empty-state placeholder with a real **world-model overview** —
a cross-cutting, actor-filtered lens over the existing models, with **no data duplication**:

- **Timeline** — calendar-dated content (`getCalendarTimelineForActor`), each event linking to its
  note in Knowledge.
- **Cast** — the actor-visible characters (`listCharactersForActor`), linking to Characters.
- **Locations** — the actor-visible maps (`listMapsForActor`), each linking to its Atlas viewer.
- **Lore** — the actor-visible notes (`getContentItemsForActor`), linking to Knowledge.

Each lens is a token card with a count, an honest per-category empty state, and cross-links to the
surface that owns the entity. A standing note explains that arcs/quests/factions arrive with a future
world-model schema and should be structured as linked Knowledge notes today (so the route is honest
about the prototype's data model rather than faking entity types that don't exist).

## Demo path / surfaces

`/campaign` with the header `View as` switch — the cast/locations/lore lists shrink for a player to
only what their visibility permits.

## Actor-safety / no-leak evidence

- Every lens renders the Processing Core's actor-filtered query
  (`listCharactersForActor` / `listMapsForActor` / `getContentItemsForActor` /
  `getCalendarTimelineForActor`), so a dm-only NPC, hidden map, private note, or dm-only dated event
  is simply absent for a player (omitted, not redacted). No new read path or visibility logic was
  introduced — Campaign is a presentation lens over the same actor-safe models.
