## Summary

Wrapped the functional `NotesWorkbench` editor in a real **editor shell** on the design tokens,
preserving every functional `note-*` / `preview-*` / `wikilink-*` testid.

- **UX-CONTENT-001 writing area:** the body is a centered prose column (`max-width: 720px`, generous
  padding, relaxed line height), `role="textbox" aria-multiline`.
- **UX-CONTENT-002 toolbar:** a sticky `role="toolbar"` with the primary six — Bold / Italic / Link /
  Code / Heading / List — that wrap the current selection (or insert at the caret) with markdown;
  Ctrl/Cmd+B, +I, +K also work from the body. 44px targets.
- **UX-CONTENT-003 slash menu:** typing `/` at the start of a line opens a `role="listbox"` insert
  menu (Heading / Quote / List / Code block / Divider) that replaces the trigger with the chosen block;
  Escape closes.
- **UX-CONTENT-004 autosave chip:** a persistent chip with four states — **Saved / Saving… / Unsaved
  changes / Save failed (retry)** — keyed off the PLAT-018 lifecycle and a dirty-tracking baseline; a
  2-second debounced **autosave** fires only when the draft actually changed and validates; the failed
  chip is itself the retry button. The chip never hides (incl. focus mode).
- **UX-CONTENT-005 split preview:** a toggle lays the rendered preview pane beside the editor (stacked
  by default); the preview is always available (`note-preview`, `aria-readonly`).
- **UX-CONTENT-007 focus mode:** a toggle hides the heading, toolbar, visibility toggle, and preview,
  leaving the centered writing area + a word-count badge and the ever-present save chip; an Exit
  control restores it.
