## Summary

Re-themed and lightly polished the graph visualization onto the semantic design tokens. Per ADR-014
the visual node-edge canvas is deferred, so the graph is the accessible **tabular** baseline (nodes
as rows with kind, tags, links-to, linked-from) plus the filter + health controls; this epic fixes
the surface's hardcoded light-only fallback colours and gives the table/filters proper token styling.
Every functional `graph-*` testid is preserved.

- Replaced `--color-text-muted` / `--color-link` / `--color-border` light-only hex fallbacks with the
  semantic tokens (so the surface themes across all five themes).
- The filter form and the simplified compact-profile filters become token cards; entity-type / source
  / relationship `<fieldset>`s and the search/tag/folder inputs get consistent token styling and 44px
  filter controls; the node table gains a header treatment and row hover. The keyboard-operable node
  links into Knowledge keep their compact link style.
