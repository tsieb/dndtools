## Summary

Brought the map annotations / nested-areas inspector surfaces onto the design tokens for visual
cohesion with the new Atlas viewer, preserving every functional `ann-*` / `route-*` / `token-*` /
`fog-*` / `overlay-*` / `nested-*` testid and all six annotation commands.

- **`MapAnnotationsPanel`** (POIs, routes, tokens, fog, combat overlay, search — MAP-010..014/018/019):
  restyled to the token system — section headers, list rows as raised cards, and **visibility badges
  with tone** (dm-only purple / player-visible blue / shared green, text always present). Inputs and
  selects meet the 44px control height; the actor-filtered search, POI create/visibility/delete, fog
  reveal/conceal (incl. offline), token move, and overlay-mode gating are unchanged.
- **`MapNestedAreas`** (embeds / nested transition — MAP-008/009/017): restyled to tokens; the
  available child shows a named, openable "Zoom into area" row, and a hidden/missing child collapses to
  one generic non-leaking placeholder.

All surfaces continue to render entirely from the single actor-filtered `getMapViewForActor` /
`resolveEmbedsForActor` read models, so they remain live no-leak proofs.
