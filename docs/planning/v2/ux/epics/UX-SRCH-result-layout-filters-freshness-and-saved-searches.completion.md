## Summary

Re-themed the global search results surface and the saved-searches/filters surface onto the semantic
design tokens — the two had hardcoded light-only fallback colours (indigo accent, white surface, grey
muted, blue link) that did not theme and read poorly on the dark default. Every functional
`global-search` / `saved-search*` / `search-result*` testid is preserved.

- **`GlobalSearch`** (UX-SRCH-002/003/004/006/007): result rows, kind/section filters, freshness
  badges, and the diagnostics fingerprint now resolve through the semantic tokens
  (`--color-accent` / `--color-accent-subtle` / `--color-text-secondary` / `--color-text-link` /
  `--color-status-error-text`) so they theme correctly across all five themes.
- **`SavedSearches`** (UX-SRCH-008): the filter builder and saved-search list re-themed the same way.
