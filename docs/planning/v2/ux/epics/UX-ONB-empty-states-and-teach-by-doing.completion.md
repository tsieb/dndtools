## Summary

Upgraded the shared empty-state pattern so every honest empty surface reads as a **teaching moment**,
not a dead end. The global `.section-empty` (used by the section-root placeholders — scene viewer,
session-privacy status, and any future planned-section root) is now a **centered teaching card**: a
prominent accent icon, a display-font title, a short "what this is + what to do" body, and a styled
`.section-empty-cta` call-to-action treatment for the first action. The change is token-only (passes
the token-contrast + quality gates) and flows to every consumer automatically.

This complements the per-surface empty states already shipped across the suite (Characters,
Knowledge, Atlas, Sync, etc.), which each state what is visible and point to the first action, and the
canvas teaching empty state (`EmptyCanvasState`, UX-CANVAS-013).

## Actor-safety / no-leak evidence

- Empty states are presentation only; the section-root placeholders state only that a deeper workspace
  is not built yet (or that nothing is visible to the actor) and never name hidden DM content — the
  teaching copy + CTA point at create/learn affordances, not at hidden data.
