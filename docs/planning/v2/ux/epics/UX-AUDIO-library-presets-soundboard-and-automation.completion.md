## Summary

The audio library / presets / soundboard / automation all live in `AudioPlayback` (the prototype
deferred a separate library-management surface to the playback widget — see the in-code note). This
epic gives the **Scene-preset cues a soundboard pad grid** (UX-AUDIO-005) and confirms the preset
association (library/presets), volume, and crossfade automation controls are token-styled.

- **UX-AUDIO-005 soundboard:** the resolved Scene presets now render as a responsive **pad grid** —
  each cue a card with the label foremost, the preset kind, a stretched accent **Play** action, and a
  Remove action — instead of a flat list, so a DM can fire cues at a glance under table pressure.
- **UX-AUDIO-004/007 library/presets:** the associate-a-preset form + bundled-preset seeding remain
  token-styled (from the prior audio epic); the resolved-preset list is the library view.
- **UX-AUDIO-006 automation:** the crossfade-seconds + volume controls are labelled token inputs, and
  the crossfade indicator honours reduced motion.
