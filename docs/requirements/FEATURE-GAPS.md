# Lamplight (`apps/gm-react`) — surface inventory

One row per surface a person can reach: what it does today, where its limits are, and which e2e
spec proves it. Rows are edited in place when the app changes, never appended to. The plan for
what is missing is [`../planning/RC_ROADMAP.md`](../planning/RC_ROADMAP.md); limits below cite the
open story that closes them rather than restating it.

## How to read a row

- **Surface**: the route and the file that owns it. Every surface reads actor-filtered core state
  and writes through `SceneRuntime.dispatch`; rows do not repeat that.
- **Honest limits**: what the surface does not do, each followed by an evidence anchor
  `` `path` › `string` ``, a literal string that exists in that file today and makes the limit true.
  Prefer in-app copy or the code that embodies the limit; for a pure absence, anchor the open
  roadmap story's title in §23.
- **E2E**: specs under `apps/gm-react/tests/e2e/` that exercise the surface on both profiles.

`pnpm feature-audit` parses the tables between the `inventory` markers and fails when any anchor
string has disappeared from its file, so a limit that was quietly closed breaks the build instead
of rotting here. A story that changes a surface edits its row in the same commit; closing a limit
means deleting it.
