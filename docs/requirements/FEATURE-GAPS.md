# Lamplight (`apps/gm-react`) — surface inventory

This requirements corpus describes reachable React surfaces and cross-cutting layers. Edit rows
in place when behavior changes. Planned work lives in the [RC roadmap](../planning/RC_ROADMAP.md).

## Evidence and validation

The RC-DOC-1.1 requirements-auditor pass reviewed these 22 surfaces and 9 layers against local
source and named specs on 2026-10-14, at code revision `81b6b34c85f88c9855c7e0ca5aab7f69b1bafdc2`.
The claims below describe implementation and assertions read, not successful execution of every
spec. Browser suites, native screen-reader/hardware checks, and deployed service configuration
were not exercised in this audit. There is no production-readiness or visual-conformance verdict.

- **What it does**: each claim carries a repo-relative `file:line` or named spec. Multiple claims
  are separated by `<br>`. A spec without a directory resolves under `apps/gm-react/tests/e2e/`.
- **Honest limits**: each limitation carries `path:line` › `literal source text`. The line locates
  the reviewed evidence; the literal text supplies the drift assertion. Separate limitations with
  `<br>`. An empty cell means no additional limitation recorded here, not complete feature parity.
- **Evidence / E2E**: implementation entry points and related specs, not test-run results. Settings,
  public readers and service adapters have their own persistence and authentication boundaries;
  the inventory makes no universal claim that all surfaces write through core dispatch.

From the repository root, run `pnpm feature-audit`. It rejects malformed/empty inventory tables,
missing behavior references, missing files/specs, out-of-range behavior references, and unanchored or
stale limits (including a literal that moved off its cited line). Literal presence alone cannot prove a limitation remains true: review the surrounding
implementation and remove closed limits in the same change that closes them. Stub and screen-wiring
probes remain informational. This audit does not inspect live accounts, credentials or deployments.
