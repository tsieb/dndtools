# Architecture Decision Records

Record a decision here when it materially affects runtime boundaries, storage, security, or platform
strategy. Start from [000-template.md](./000-template.md), take the next number (never reused),
cross-link supersedes and amendments in both directions, and keep the Status cell below identical to
the ADR's own `Status:` line. Update an ADR in the same change that changes its implementation.

ADRs 001–013 predate the React pivot (ADR-018). The ones marked Retired described the removed v1
runtime and are kept only as history; the rest still govern and cite current paths.
