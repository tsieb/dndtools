## Token-layer landmines (read BEFORE writing any color/theme finding)
- **`--color-visibility-dm{,-subtle}` are UNDEFINED** yet written at 7 sites in PlayerView/Player/Community → DM-only banners lose their border AND tint. Real names: `--color-dm-only-badge{,-subtle}`. [[ds-layer-audit]] item 9.
- `:root` `--layer-*` are LIGHT (tuned for the dark map well); only parchment re-cut them DARK. So a white glyph on them (POIMarker) breaks in the DEFAULT theme, not parchment — check which theme before claiming contrast.
- No on-fill foreground token exists for status colours (`-text` is for `-subtle` backgrounds), so `Button` danger's `#fff` can't be fixed by swapping in an existing token.
- **`--layer-terrain` IS NOW DECLARED** (colors.css:267/:304/:416) as of run #10 — the old "undefined, Grass==Forest" claim is DEAD. Guard: `app/map/mapVocab.test.ts` (compares swatch STRINGS, so near-identical rendered colours still slip through).
- ~~`isolateModalSiblings` inerts the `ToastViewport`~~ **FIXED at 9aeebdde** — `modalIsolation.ts:23` now skips any sibling with `data-modal-exempt`, which `ToastViewport` sets. Toasts raised from inside a Dialog/Sheet/MapEditor are live again. Do NOT re-report.
- **The mobile Playwright profile is `devices['Pixel 5']` = 393×851, NOT 375.** Phone content box after `Page` padding ≈ 365px; inside a `Panel` (pad 18 + border) ≈ 327px. Use these numbers before claiming a `minmax(Npx,1fr)` grid overflows — 260px and 300px tracks both fit.
- **NO global `button:hover` exists** — `src/styles/index.css` contains 0 occurrences of "hover". Every inline-styled `<button>` in a screen has ZERO pointer feedback unless it hand-rolls `useState` hover (`Knowledge.tsx` `RelRow` is the in-repo pattern). This is a systemic finding, not a per-site one.
- **`touchAction:'none'` on a read-only canvas = phone scroll trap.** `MapBuilder.tsx:687` sets it unconditionally although `onWellPointerDown` bails when `!editable`. Precedent for the fix: `SceneBoardCanvas.tsx:480` gates it (`policy === 'bounded' ? 'pan-y' : 'none'`). No responsive gate detects this — `clippedControls` is X-axis + viewport-relative only.
- Dead DS exports, ZERO consumers — don't spend fix effort: `Tooltip` (its clipping bug is therefore latent), `NavSidebar`/`NavItem`, `DataTable`'s `sortable`, and the `colors.css` legacy alias bridge (`--bg/--fg/--card/…`). `DataTable`'s missing overflow wrapper IS live, though.
